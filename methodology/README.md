Методические документы лежат в этой папке. Способ шага берётся только отсюда. Пока документа шага нет, агент не подменяет его собственным методом. Порядок шагов и существенный выбор записаны в `agent/instructions.md`.

- Постановка — `postanovka.md`
- Материалы — `materialy.md`
- Исследование — `issledovanie.md`
- Варианты — `varianty.md`
- Стратегии — `strategii.md`
- Решение — `reshenie.md`

План проверки — третий шаблон в `strategii.md`, отдельного документа у него нет. Карточка решения пишется после принятия результата. Правило обновления при новых данных — в `reshenie.md`.
