# Стратег Фабрики продуктов

Папка для работы руководителя цифрового продукта с агентом. Агент сам ведёт задачу от размытой формулировки до стратегий и плана проверки.

## Как начать

1. В Cursor выберите File → Open Folder и откройте именно эту папку. Родительскую папку открывать не нужно.
2. Откройте новый чат в режиме Agent.
3. Напишите запрос обычным языком, даже если он ещё размытый. Внутренние файлы прикладывать не нужно.

Пример: «Хотим запустить сервис для семьи, пока неясно, нужен ли он».

## Как продолжить

Закройте чат. В той же папке откройте новый чат и напишите «продолжай». Историю пересказывать не нужно.

## Когда нужен ответ

Агент спрашивает, какое одно направление брать в стратегии и что исправить в готовом результате. Если запрос не называет одно направление, вопрос будет и об этом. Остановить работу, уточнить задачу или поправить вывод можно своими словами в любом сообщении.

## Ключи

Скопируйте `.env.example` в `.env` и заполните его только у себя на компьютере. Файл `.env` в репозиторий не попадает.

## Где что лежит

- Постоянные инструкции агента: `agent/instructions.md`
- Методика: `methodology/`
- Материалы проекта: `materials/`
- Состояние текущей задачи: `task/state.md`
- Журнал работы: `journal/log.md`
