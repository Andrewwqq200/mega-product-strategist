Здесь лежат материалы одного проекта: бриф, заметки и выдержки. Другого места для материалов агент не заводит.

Реестр карточек — `sources.md`. Файл появляется с первым источником. Выписки — папка `extracts/`: у карточки `sNN` файл `extracts/sNN.md`. В `task/state.md` текст источника не копируется, остаётся путь к реестру.

Исследование — `issledovanie.md`. Файл появляется на шаге «Исследование». Реестр и выписки остаются местом источников. В `task/state.md` текст выводов не копируется, остаётся путь к файлу исследования.
